# **App Name**: HireFit AI

## Core Features:

- Intelligent Resume Evaluation Engine (H.I.R.E): An AI tool that parses uploaded documents and job descriptions to provide real-time match scores and profile reasoning.
- Recruiter View Mode: An AI tool that simulates recruiter behavior to provide shortlist probability and qualitative hiring decisions.
- Application Readiness Score: An AI tool that aggregates ATS compatibility, match accuracy, and content quality into a single readiness metric.
- Industry Benchmarking: An AI tool used to evaluate resume strength against specific industry cohorts and percentile rankings.
- AI Career Coach: An AI tool that provides reasoning for personalized career trajectories and specific learning recommendations.
- Resume Health Dashboard: A visual bento-grid control center displaying metrics for keyword coverage, achievement strength, and formatting.
- Resume Version Management: A version-control system to save, compare, and track score improvements across multiple resume iterations.
- Achievement Bullet Optimizer: An AI tool that contextually transforms passive bullet points into high-impact, result-driven statements.
- Dynamic Skill Gap Learning Roadmap: An AI tool that generates time-bound technical learning plans focused on bridging identified professional gaps.
- Automated Personalization Suite: An AI tool that drafts tailored cover letters by reasoning through employer requirements and company tone.
- Downloadable PDF Reports: Generates professional branded PDF documents containing full ATS analysis and recruiter insights.

## Style Guidelines:

- Premium Monochrome Onyx theme with deep matte black (#0A0A0A), white (#FFFFFF), and Silver Industrial (#94A3B8) borders.
- Headlines use 'Space Grotesk' for a high-tech feel, while body text uses 'Inter' for data-heavy readability.
- Ultra-thin linear icons with a 1.5px stroke weight for a precise, modern productivity tool aesthetic.
- Command Center architecture featuring persistent sidebars and interactive bento-grid metric cards.
- Mouse-scroll synchronized video playback in the hero section and liquid-smooth CSS state transitions.
